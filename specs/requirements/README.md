# Requirements

Este directorio contiene las especificaciones de requisitos aplicables al frontend del sistema.

## Contenido

Aquí se almacenan, según corresponda:

- Requisitos funcionales asociados al frontend
- Requisitos no funcionales aplicables al frontend
- Flujos de usuario
- Comportamientos esperados de las interfaces
- Validaciones de interfaz

Los cambios que modifiquen el comportamiento funcional del frontend deben actualizar primero la especificación correspondiente antes de su implementación.
