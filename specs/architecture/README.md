# Architecture

Este directorio contiene las especificaciones y decisiones de arquitectura relacionadas con el frontend del sistema.

## Contenido

Aquí se almacenan, según corresponda:

- Arquitectura del frontend

- Gestión de estado
- Integración con APIs
- Restricciones y lineamientos técnicos

Las decisiones arquitectónicas formales se registran en el directorio `adr/`.
