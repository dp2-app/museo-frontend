# Import

Este directorio contiene las especificaciones de interfaz y comportamiento relacionadas con el proceso de importación.

## Contenido

Aquí se almacenan, según corresponda:

- Flujo de carga de archivos
- Previsualización de información
- Presentación de errores y advertencias
- Confirmaciones del usuario
- Estados del proceso de importación
- Interacción con los servicios de importación

Los cambios que modifiquen el comportamiento de la interfaz de importación deben actualizar primero la especificación correspondiente.
